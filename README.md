# 🧠 Webpage Summarizer Extension

Too many tabs, not enough time? This extension is your shortcut to smarter reading!  
It uses **NLP magic** to scan any webpage and give you a quick, clean summary of the key points 🧃📄.

---

## 🚀 What It Does

- 📄 Summarizes articles in 1 click  
- ⏱ Saves time by cutting the fluff  
- 🧠 Helps you grasp ideas instantly

---

## ⚙️ Tech Stack

- JavaScript + HTML/CSS (Extension UI)  
- NLP (TextRank / Transformers-based summarizer)

---

## 🛠️ How to Use

1. Load the extension in your browser  
2. Click **🧠 Summarize** on any page  
3. Read less, know more!
